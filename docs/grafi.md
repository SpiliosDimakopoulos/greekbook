# Γράψιμο σε Markdown

Το greekbook δέχεται τυπικό Markdown (CommonMark) και τις επεκτάσεις του Pandoc που
χρησιμοποιούνται σε εργασίες και βιβλία.

## Κείμενο

| Γράφεις | Παίρνεις |
|---|---|
| κενή γραμμή | νέα παράγραφο |
| `*πλάγια*`, `**έντονα**`, `~~διαγραφή~~` | *πλάγια*, **έντονα**, ~~διαγραφή~~ |
| `"κείμενο"` | «κείμενο»· μέσα σε εισαγωγικά: «… “…” …» |
| `---`, `--`, `...` | παύλα —, ενωτικό –, αποσιωπητικά … |
| `σ' αγαπώ` | σ’ αγαπώ |
| δύο κενά στο τέλος γραμμής | αλλαγή γραμμής |
| `` `κώδικας` `` | `κώδικας` |
| `[σύνδεσμος](https://typst.app)` | σύνδεσμος |

## Δομή

```markdown
# Κεφάλαιο {#sec:intro}        ← κεφάλαιο με ετικέτα για παραπομπές
## Ενότητα
### Υποενότητα
# Πρόλογος {-}                 ← χωρίς αριθμό
# Μέρος πρώτο {.part}          ← σελίδα «ΜΕΡΟΣ ΠΡΩΤΟ»

---                            ← αλλαγή σκηνής ⁂ (ανάμεσα σε παραγράφους)
\newpage                       ← αλλαγή σελίδας
```

## Λίστες και παραθέματα

```markdown
- κουκκίδα
    - εμφωλευμένη
1. αριθμημένη
2. λίστα

> Παράθεμα σε ξεχωριστό μπλοκ.
```

## Υποσημειώσεις

```markdown
Κείμενο με σημείωση[^1] ή με ενσωματωμένη σημείωση^[εδώ γράφεται κατευθείαν].

[^1]: Το κείμενο της σημείωσης.
```

## Σχήματα και πίνακες

```markdown
![Λεζάντα σχήματος.](figures/xartis.png){#fig:xartis width=70%}

| Στήλη | Αριθμός |
|:------|--------:|
| α     | 1,5     |

Table: Λεζάντα πίνακα. {#tbl:apotelesmata}
```

Οι εικόνες μπορούν να είναι PNG, JPEG, GIF, SVG ή WebP. Η στοίχιση των στηλών
ορίζεται με τις άνω-κάτω τελείες της δεύτερης γραμμής.

## Μαθηματικά

Σε σύνταξη LaTeX:

```markdown
Η ενέργεια $E = mc^2$ μέσα στο κείμενο, ή σε δική της γραμμή:

$$ \int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2} $$ (eq:gauss)
```

Αν προτιμάς τη σύνταξη του Typst, βάλε `math: typst` στο `book.yaml`.

## Παραπομπές

| Γράφεις | Παίρνεις (APA) |
|---|---|
| `[@knuth1984]` | (Knuth, 1984) |
| `[@knuth1984, σ. 12]` | (Knuth, 1984, σ. 12) |
| `[@a; @b]` | (A, 2020; B, 2021) |
| `@knuth1984 έδειξε` | Knuth (1984) έδειξε |
| `[-@knuth1984]` | (1984) |
| `@fig:xartis`, `@tbl:x`, `@eq:x`, `@sec:x` | Σχήμα 2.1, Πίνακας 3.1, Εξίσωση (2.1), Κεφάλαιο 1 |
| `[-@tbl:x]` | μόνο ο αριθμός: 3.1 |
